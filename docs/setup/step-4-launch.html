Launch & Verify

Activate workflows, test with a real MR, and verify everything works end-to-end.

4.1 Activate Workflows

  1. In n8n, open workflow-main → toggle "Active" switch (top right) to ON (green)
  2. Open workflow-approval → toggle "Active" to ON

Both workflows should now show as Active in your workflow list.

4.2 Test with a Real MR

  1. Go to your GitLab project and create a new branch with some code changes (ideally with an intentional issue like SQL injection or missing error handling)
  2. Create a Merge Request from that branch
  3. Wait 30–60 seconds and refresh the MR page
  4. You should see a draft comment like this:
    Expected Draft Comment
    ## AI Code Review - Pending CTO Approval ### Executive Summary Risk Level: MEDIUM (Score: 35/100) | AI Confidence: 82% Recommendation: REVIEW RECOMMENDED ### Findings: #1 [HIGH] SQL Injection Vulnerability - security File: src/api/users.py:12 ... ### CTO Action Required Reply with: !approve, !reject, or !approve-partial 1,3

4.3 Test CTO Commands

Reply to the draft comment with these commands (click to copy):

!approve Post all findings click to copy
!reject Discard review click to copy
!approve-partial 1,2 Post selected only click to copy
!list-findings Re-display findings click to copy
!explain 1 Detailed explanation click to copy
!remove-finding 2 Remove a finding click to copy
!edit-finding 1 severity:low Change severity click to copy
!rerun-agent security Re-run an agent click to copy
!add-comment file:line "msg" Custom comment click to copy

Click each item as you verify it:

4.5 Troubleshooting

Webhook not triggering ▾
  • Check GitLab webhook → Recent deliveries for error codes
  • Verify n8n is reachable from GitLab (same network / public URL)
  • Ensure both workflows are Active in n8n
  • Double-check webhook URL has no typos
Database connection error ▾
  • Set SSL to "Allow" in n8n Postgres credential
  • Verify Supabase project is not paused (free tier pauses after inactivity)
  • Check password is correct (no extra spaces)
  • Ensure pgcrypto extension was enabled in migration
OpenRouter API returns 401 or 403 ▾
  • Make sure the Header Auth value is Bearer sk-or-v1-xxx (with "Bearer " prefix and space)
  • Check that you have credits on OpenRouter
  • Try changing OPENROUTER_MODEL to a different model
Inline comments not appearing after !approve ▾
  • Ensure GitLab token has api scope (not just read_api)
  • Check n8n execution logs for the approval workflow
  • Verify SHA values are stored in pending_reviews (needed for positioning)
  • Comments are posted in batches of 5 with 1s delay — wait a few seconds
No draft comment appears on MR ▾
  • Check n8n Executions page for the main workflow — look for errors
  • Usually a credential is missing on one of the nodes
  • Verify the MR event filter is not blocking your event (check the Filter node)
  • Try opening/updating the MR again to re-trigger the webhook
