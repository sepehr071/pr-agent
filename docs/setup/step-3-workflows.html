Import Workflows & Webhooks

Import the two workflow JSON files into n8n, connect credentials to each node, and wire up GitLab webhooks.

3.1 Import Workflow Files

  1. In n8n, click "Add workflow" (top right)
  2. Click the ⋮ menu → "Import from File"
  3. Select workflow-main.json → Save
  4. Repeat: Add workflow → Import → workflow-approval.json → Save

3.2 Connect Credentials to Nodes

Open each node and assign the matching credential from Step 2:

workflow-main.json (Review Pipeline)

GitLab Self-Hosted

  • GitLab MR Trigger

GitLab Private Token

  • Fetch MR Diff
  • Post Draft Comment to GitLab

OpenRouter API

  • Security Review Agent
  • Performance Review Agent
  • Style Review Agent
  • Architecture Review Agent
  • Test Coverage Agent
  • Code Quality Agent
  • Context Analyzer Agent

PostgreSQL

  • Store Pending Review
  • Record Agent Runs
  • Fetch Project Patterns

workflow-approval.json (CTO Command Handler)

GitLab Self-Hosted

  • GitLab Note Trigger

GitLab Private Token

  • All "Post *" nodes
  • All "Create Discussion *" nodes
  • All "Update MR *" nodes

PostgreSQL

  • All "Fetch Review *" nodes
  • All "Update Review *" nodes
  • All "Insert *" nodes

OpenRouter API

  • Explain Finding (AI call)
  • Re-run Agent (AI call)
Tip
The approval workflow has multiple paths (11 command types). Many paths have similar node names. Click through each path and make sure every node with a credential icon has one assigned.

3.3 Get Webhook URLs from n8n

  1. Open workflow-main → click the GitLab MR Trigger node → find "Webhook URLs" section → copy the Production URL
  2. Open workflow-approval → click the GitLab Note Trigger node → copy the Production URL

Example URLs

https://your-n8n.com/webhook/a1b2c3d4-main
https://your-n8n.com/webhook/e5f6g7h8-approval

3.4 Configure GitLab Webhooks

Go to your GitLab project → Settings → Webhooks and add two webhooks:

#URL (from 3.3)TriggerSSL
1 Main workflow webhook URL Merge request events Enable
2 Approval workflow webhook URL Note (comment) events Enable
  1. Click "Add new webhook"
  2. Paste the main workflow URL → check "Merge request events" → enable SSL → Add webhook
  3. Click "Add new webhook" again
  4. Paste the approval workflow URL → check "Comments" → enable SSL → Add webhook
  5. Click "Test" on each webhook — you should see a green checkmark
Self-hosted n8n?
Make sure your n8n instance is reachable from your GitLab server. If they're on the same network, use the internal IP/hostname. If GitLab can't reach n8n, webhooks will silently fail.
