API Keys & n8n Configuration

Generate your API tokens and configure n8n credentials and environment variables.

2.1 GitLab Personal Access Token

  1. In your GitLab instance, go to Profile → Preferences → Access Tokens
  2. Create a new token:
    Namen8n-mr-review
    Scopesapi (required!)
    ExpirationAs needed (or no expiry)
  3. Click "Create personal access token"
  4. Copy the token immediately — it's shown only once

2.2 OpenRouter API Key

  1. Go to https://openrouter.ai and sign up
  2. Navigate to Keys → Create Key
  3. Copy the key (starts with sk-or-)

2.3 Add Credentials in n8n

Go to n8n → Credentials → Add Credential and create all four:

2.4 Set Environment Variables

Go to n8n → Settings → Variables (or add to your .env file if self-hosted):

Environment Variables
GITLAB_URL=https://your-gitlab.com GITLAB_NAMESPACE=your-group GITLAB_PROJECT=your-project OPENROUTER_MODEL=anthropic/claude-3.5-sonnet APP_URL=https://yourcompany.com AUTHORIZED_APPROVERS=cto,tech-lead,yourname MIN_SEVERITY=low REVIEW_MODE=thorough MAX_FINDINGS_PER_AGENT=20
VariableDescriptionRequired
GITLAB_URLYour GitLab instance URL (no trailing slash)Yes
GITLAB_NAMESPACEGroup or username that owns the projectYes
GITLAB_PROJECTProject/repo nameYes
OPENROUTER_MODELAI model for reviewsYes
APP_URLYour company URL (shown in review header)Yes
AUTHORIZED_APPROVERSComma-separated GitLab usernamesYes
MIN_SEVERITYcritical / high / medium / lowYes
REVIEW_MODEthorough / balanced / quickYes
MAX_FINDINGS_PER_AGENTCap per agent to reduce noiseYes
CRITICAL_NOTIFICATION_WEBHOOKSlack/Teams webhook for critical alertsNo
Tip: REVIEW_MODE
thorough = detailed analysis, more findings (~60s). balanced = good coverage, moderate speed (~40s). quick = fast scan, high severity only (~20s).
