📝 Step-by-Step: Creating Credentials

  • 1

    Get GitLab Personal Access Token

    Go to GitLab → Profile → Preferences → Access Tokens → Create new token with api scope

  • 2

    Get OpenRouter API Key

    Go to openrouter.ai → Keys → Create Key (starts with sk-or-)

  • 3

    Create Supabase Project

    Go to supabase.com → New Project → Save database password!

  • 4

    Create Credentials in n8n

    In n8n, go to Credentials → Add Credential → Select type → Fill in details → Save

💾 Supabase Database Setup

  • 1

    Create Supabase Project

    Go to supabase.com → New Project → Name: gitlab-reviews → Save password!

  • 2

    Open SQL Editor

    In Supabase dashboard, click SQL Editor (left sidebar) → New query

  • 3

    Run this SQL

    CREATE TABLE pending_reviews (
    id SERIAL PRIMARY KEY,
    review_id VARCHAR(255) UNIQUE NOT NULL,
    mr_iid INTEGER NOT NULL,
    project_id INTEGER NOT NULL,
    findings JSONB NOT NULL,
    stats JSONB,
    draft_note_id INTEGER,
    base_sha VARCHAR(64),
    head_sha VARCHAR(64),
    start_sha VARCHAR(64),
    status VARCHAR(50) DEFAULT 'pending_approval',
    approved_by VARCHAR(255),
    approved_at TIMESTAMP,
    rejected_by VARCHAR(255),
    rejected_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_pending_reviews_review_id
    ON pending_reviews(review_id);
CREATE INDEX idx_pending_reviews_status
    ON pending_reviews(status);
CREATE INDEX idx_pending_reviews_mr
    ON pending_reviews(project_id, mr_iid);
  • 4

    Run v3.0 Migration (Optional)

    Open database/migration-v3.sql and run it for learning features + enhanced columns

🔧 Troubleshooting

Webhook not triggering
Check GitLab webhook shows green checkmark
Database connection error
Verify SSL is "Allow" in n8n credential
OpenRouter API error
Check "Bearer " prefix in API key
Inline comments not appearing
Check GitLab token has api scope
Supabase paused
Check Supabase project is not paused (free tier)
Unauthorized error
Add your username to AUTHORIZED_APPROVERS
